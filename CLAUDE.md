# Project rules

## Always apply be-ambitious
Before starting ANY task in this repo, apply the be-ambitious skill (.claude/skills/be-ambitious/SKILL.md):
- State the goal beyond the goal in one line.
- Pick the types that fit (Altitude / Depth / Range).
- Name the outside judge (a test, screenshot, measurement) that will prove the result.
Then do the task at that level. Keep it short for small tasks. Ambition raises the standard, not the permissions: ask before anything that changes what I asked for, spends money, or can't be undone.
